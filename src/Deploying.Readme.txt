AI Interview runtime completion idempotency note:
The AI Interview plugin's final-submit scoring and completion publication are serialized by process-local keyed locks. Run the runtime on a single application instance, or use routing that guarantees all requests for one interview session reach the same instance. The current plugin does not claim durable cross-instance exactly-once scoring/publication; enabling platform load balancers, proxies, or distributed cache does not make the AI Interview completion lock distributed.
